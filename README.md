# Study03_Quiz — 상식 퀴즈

혼자 상식을 공부하는 대학 1학년 학생을 위한 4지선다 퀴즈 웹 앱입니다. 답을 고르면 바로 정답 여부와 한 줄 해설, 출처를 보여 주므로 틀린 문제를 그 자리에서 확인하고 넘어갈 수 있습니다.

## 실행 방법

설치나 서버가 필요 없습니다. 저장소를 내려받은 뒤 `index.html`을 더블클릭해 브라우저에서 여세요.

## 기능

- **카테고리 4개:** 한국사, 세계지리, 과학, 예술과 문화에 10문항 이상씩 있습니다. 한 판은 카테고리 하나에서 무작위로 뽑은 10문제이고, 매 판 문제와 보기의 순서가 섞입니다.
- **즉시 해설:** 답을 고르면 정답에 ✔, 고른 오답에 ✘가 붙고 한 줄 해설과 출처 링크가 나옵니다.
- **게임 모드 3개**

  | 모드 | 규칙 | 순위표 |
  |---|---|---|
  | 연습 | 시간 제한과 감점이 없고, 끝난 뒤 틀린 문제만 다시 풀 수 있음 | 기록 안 함 |
  | 스피드 | 문항마다 15초, 시간이 지나면 오답 | 기록함 |
  | 힌트 | 문항마다 한 번 오답 2개를 지울 수 있고, 쓰고 맞히면 0.5점 | 기록함 |

- **점수 저장과 순위표:** 스피드와 힌트 모드의 기록을 브라우저(localStorage)에 저장하고, 카테고리와 모드마다 상위 5개를 보여 줍니다. 기록은 그 브라우저에만 남습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 틀 |
| `style.css` | 화면 모양(밝은/어두운 테마, 휴대폰 폭 대응) |
| `script.js` | 퀴즈 동작, 모드, 점수 저장 |
| `questions.js` | 40문항 자료(문제, 보기, 정답, 해설, 출처) |
| `PRD.md` | 요구사항 문서 |
| `IMPL-PLAN.md` | 3단계 구현 계획 |
| `CLAUDE.md` | 문항을 만들고 고칠 때의 규칙 |

## 개발 단계

세 단계로 나눠 만들었고, 단계마다 태그를 달았습니다.

| 태그 | 내용 |
|---|---|
| `stage-1` | 기본 퀴즈와 점수 |
| `stage-2` | 게임 모드 3개(연습, 스피드, 힌트) |
| `stage-3` | 점수 저장과 순위표 |

## 문항 규칙

문항은 출처를 확인해서 만들었고, 해설 아래에 출처를 적었습니다. 문항을 만들거나 고칠 때의 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다. 문항에 잘못된 내용이 있으면 이슈로 알려 주세요.
