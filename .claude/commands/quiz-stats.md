# 문항 통계

`questions.js`의 문항을 세어 카테고리별, 난이도별 문항 수를 보고한다.

## 지켜야 할 것

- **파일을 고치지 않는다.** `questions.js`를 비롯한 어떤 파일도 만들거나 고치거나 지우지 않는다. 결과는 대화창에만 보고한다.
- 어림하지 않는다. `questions.js`를 직접 읽고 문항 객체를 하나씩 세어 나온 수만 적는다.

## 순서

1. `questions.js`를 읽는다. 카테고리 목록은 `script.js`의 `CATEGORIES`를 따른다(한국사, 세계지리, 과학, 예술과 문화).
2. 문항 객체마다 `category`와 `difficulty`를 모은다.
   - `difficulty`는 `쉬움`, `보통`, `어려움` 가운데 하나다.
   - `difficulty`가 없거나 이 세 값이 아니면 `미지정`으로 센다.
3. 아래 "보고 형식"대로 보고한다.

## 보고 형식

1. 첫 줄에 전체 문항 수를 한 문장으로 쓴다. 예: "전체 41문항입니다."
2. 카테고리별 문항 수 표. `CATEGORIES`에 없는 카테고리가 있으면 그 이름으로 한 행을 더 쓴다.

| 카테고리 | 문항 수 |
|---|---|
| 한국사 | (개수) |
| 세계지리 | (개수) |
| 과학 | (개수) |
| 예술과 문화 | (개수) |
| 합계 | (개수) |

3. 난이도별 문항 수 표. 카테고리와 난이도를 교차해 센다. 문항이 0개인 칸은 `0`으로 적는다.

| 카테고리 | 쉬움 | 보통 | 어려움 | 미지정 | 합계 |
|---|---|---|---|---|---|
| 한국사 | | | | | |
| 세계지리 | | | | | |
| 과학 | | | | | |
| 예술과 문화 | | | | | |
| 합계 | | | | | |

4. 표 아래에 필요한 것만 짧게 적는다.
   - 10문항보다 적은 카테고리가 있으면 "앱의 자료 검사(카테고리마다 10문항 이상)에 걸립니다"라고 적는다.
   - `미지정`이 있으면 그 수를 적고, 난이도가 `difficulty` 칸에 적힌 문항만 난이도별로 셀 수 있다고 밝힌다.
   - `difficulty`에 세 값이 아닌 값이 있으면 그 문항 id와 값을 적는다.
5. 마지막에 "파일은 고치지 않았습니다."라고 쓴다.
