# 매일 문항 추가

아래 3단계를 순서대로 한다. 각 단계는 이미 있는 명령어 파일의 절차를 그대로 따른다. 이 파일에 따로 적은 것만 다르게 한다.

- 1단계: `.claude/commands/quiz-add.md`
- 2단계: `.claude/commands/quiz-validate.md`
- 3단계: `.claude/commands/quiz-stats.md`

각 단계를 시작할 때 그 명령어 파일을 새로 읽는다. 단계가 끝나면 한 줄로 「N단계 완료」를 출력한다(예: 「1단계 완료」).

## 지켜야 할 것

- 고치는 파일은 `questions.js` 하나뿐이고, 1단계에서 승인받은 뒤에만 고친다. 2·3단계에서는 어떤 파일도 고치지 않는다.
- 규칙의 기준은 `CLAUDE.md`를 따른다. 명령어 파일과 `CLAUDE.md`가 다르면 `CLAUDE.md`를 따른다.
- 확인하지 못한 것을 확인했다고 쓰지 않는다.

## 1단계: 문항 4개 추가

`quiz-add.md`의 절차를 카테고리 4개(한국사, 세계지리, 과학, 예술과 문화)에 난이도 `보통`으로 한 번씩 적용한다. 다만 승인은 4개를 한꺼번에 받는다.

1. 카테고리마다 `quiz-add.md`의 1~3단계(읽기, 문항 만들기, 규칙 확인)를 한다. 이때는 파일을 고치지 않는다.
2. 4개가 모두 준비되면 `quiz-add.md` 4단계 형식으로 4문항을 차례로 이어서 보여 준다. 그다음 "4문항을 모두 넣을까요? 고칠 문항이 있으면 id와 함께 알려 주세요."라고 한 번만 묻고, **턴을 끝내고 기다린다.**
3. 답에 따라 한다.
   - **승인**: 4문항을 모두 `quiz-add.md` 6단계대로 넣고, 넣은 id 4개를 한 줄로 알린다. 카테고리별 문항 수는 3단계에서 보고하므로 `quiz-add.md` 7단계의 표는 생략한다.
   - **일부 수정 요청**: 말한 문항만 고치고 규칙 확인을 다시 한 뒤, 4문항 전체를 다시 보여 주고 다시 한 번에 승인을 받는다.
   - **거절**: 파일을 고치지 않고 "1단계에서 멈춤: 승인받지 못함"이라고 쓴 뒤 끝낸다. 2·3단계는 하지 않는다.
   - 애매한 답이면 넣지 말고 다시 묻는다. 4문항 가운데 일부만 넣지 않는다.
4. 「1단계 완료」를 출력한다.

## 2단계: 전체 점검

`quiz-validate.md`의 절차를 인수 없이(전체 문항) 따른다. 1단계에서 넣은 문항도 포함한다. 문항이 많으면 Agent 도구로 카테고리별로 나눠 동시에 점검해도 된다.

- `quiz-validate.md`의 "보고 형식"대로 보고한다.
- **어긋나는 문항이 1개라도 있으면** 보고 뒤에 "2단계에서 멈춤: 어긋나는 문항 N개"라고 쓰고 끝낸다. 3단계는 하지 않는다. 1단계에서 넣은 문항은 되돌리지 않는다.
- "확인 못 함"만 있고 어긋나는 문항이 없으면 멈추지 않는다. 확인 못 함 표는 그대로 보여 준다.
- 어긋나는 문항이 없으면 「2단계 완료」를 출력한다.

## 3단계: 현황 보고

`quiz-stats.md`의 절차대로 카테고리별, 난이도별 문항 수를 보고한다. 그다음 「3단계 완료」를 출력한다.
